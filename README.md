# Resource Library

냜인용 웹 프로젝트 리소스 저장소입니다.
이미지, 스크린샷, 로고, 목업, UI 컴포넌트 등을 체계적으로 관리하고 URL로 활용할 수 있습니다.

## 📁 폴더 구조

Resource/
- Images/ : 웹 프로젝트에서 사용할 이미지들
- Screenshots/ : 프로젝트 스크린샷 및 데모 이미지
- Logos/ : 로고 및 아이콘 리소스
- Mockups/ : 디자인 목업 및 프로토타입
- UI-Components/ : UI 컴포넌트 이미지

## 🚀 사용 방법

### 이미지 업로드
1. 해당 폴더로 이동
2. 파일 업로드 또는 drag & drop
3. GitHub 원시 파일 URL 복사

### 날 리소스
- Private Repository: 개인 전용
- 모든 폴더에 .gitkeep 파일 포함
- 단순 이미지 URL: https://raw.githubusercontent.com/Demian-Yim/Resource/Hompage/[FOLDER]/[filename]
